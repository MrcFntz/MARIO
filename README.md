# MARIO

*MARIO: a user-friendly tool for Morphometric Analysis and quantitative Readout of Intracellular Organelles from fluorescence images.*

MARIO is a standalone Matlab free-to-use and user-friendly tool developed as a joint effort between the Bortolozzi and Carrer lab at the Veneto Institute of Molecular Medicine (VIMM) in Padua, Italy.
This tool is able to perform Morphometric Analysis and quantitative Readout of Intracellular Organelles from fluorescence images and to provide easily interpretable and consistent descriptors for both organellar shape and network organization.

**Prerequisites**

MATLAB Runtime 2019b
Download and install this version of the MATLAB Runtime from here:
https://it.mathworks.com/products/compiler/matlab-runtime.html
