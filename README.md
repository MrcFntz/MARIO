# MARIO
Multiple Automated Recognition of Intracellular Organelles

MARIO is a standalone Matlab free-to-use and user-friendly tool developed as a joint effort between the Bortolozzi and Carrer lab at the Veneto Institute of Molecular Medicine (VIMM) in Padua, Italy.
This tool is able to perform Multiple Automated Recognition of Intracellular Organelles and to provide easily interpretable and consistent descriptors for both organellar shape and network organization.
